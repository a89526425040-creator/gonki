# Gonki — 3D Coin Collector

3D arcade driving game made with Godot 4.4.1. The arena, car and coins are generated procedurally.

## Controls
- WASD or arrow keys — drive
- Collect the gold coins around the arena

## Windows build
GitHub Actions builds the Windows x86_64 version on every push to main. Open Actions, select the latest successful **Build Windows game** run, and download the **Gonki-Windows** artifact. Extract the ZIP and launch Gonki.exe.
